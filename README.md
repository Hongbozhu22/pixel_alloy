# 像素合金 v2.0

一款纯 HTML5 Canvas 打造的横版像素射击游戏，致敬《合金弹头》。

## 特性
- 武器系统：突击步枪 / 双刀
- 弹反与修罗拔刀大招
- 三关卡 Boss 战 + 剧情对话
- 粒子效果与打击感
- 单文件运行，双击即玩

## 运行
直接双击 `Pixel Alloy.html` 即可。

## 操作
| 键位 | 功能 |
|------|------|
| A / D | 左右移动 |
| S | 下蹲 |
| 空格 | 跳跃 |
| W + J | 向上射击 / 气刃 |
| J | 攻击 1（射击 / 轻刀剑气） |
| K | 攻击 2（手雷 / 重刀·弹反） |
| L | 防御（盾 / 冲刺） |
| I | 大招（能量满）/ 使用道具 |
| R | 切换道具 |
| Tab | 商店 |
| P | 跳过对话 |
